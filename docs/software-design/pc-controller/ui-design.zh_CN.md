# UI 设计：PC Controller（FUI 赛博朋克 HUD）

**适用范围：** AI PASSPORT 开发板（ESP32-C3，ST7789 240×320 竖屏，RGB565，单缓冲 240×20 行，无 TE 信号）上的 PC Controller 应用构建配置。

**基线：** 已确认的 UI 决策（2026-08-30），视觉样机 fui-v6。

量化验收指标由同目录 `requirements.md` 维护（单一事实源）；本文涉及处仅注明“见 requirements.md”，不复制数字。

## 1. 设计语言（Design Language）

PC Controller 全部界面采用 Nicolas Lopardo 风格的 FUI 赛博朋克 HUD：深海军蓝底、橙色发光面板、荧光黄状态字、青色标签、HUD 像素字体、网格/扫描线底纹、面板四角括号、CRT 扫描线质感。

设计理由——该风格不仅是审美选择，更是对显示硬件的直接适配：

- 屏幕**无 TE 信号**，且使用**单缓冲 240×20 行**（`components/bsp/src/bsp_display_lvgl.c`，`double_buffer = false`）。每一帧都存在撕裂窗口，而撕裂只在内容变化处可见。
- 深色底加少量小面积亮色元素能把每帧脏区压到最小，因此核心纪律是**“整屏静态、局部流动”**。
- 深底＋细亮线＋局部动效是单缓冲无 TE 管线下代价最低的负载：亮色压暗底的 HUD 图形撕裂不易察觉，亮底高对比构图则会把每条撕裂线暴露无遗。

屏幕文字全英文。设备无 CJK 字库，也不会引入（见第 6 章）。

## 2. 设计令牌（Design Tokens）

下表令牌是配色与面板装饰的唯一事实源。

| 令牌 | 取值 | 用途 |
|---|---|---|
| `BG` | `#0B1030` | 全屏背景（深海军蓝） |
| `PANEL_BG` | `#0D1338` | 面板底色 |
| `PANEL_GLOW` | `#F07818` | 面板边框、发光与主强调色（橙） |
| `STATUS` | `#FFD700` | 状态字、按键名、h1、四角括号（荧光黄） |
| `LABEL` | `#3FE0F0` | 面板标签、顶栏模式名、计时器数字（青） |
| `TEXT` | `#EAF2FF` | 正文（白） |
| `FRAME` | `#2A2F55` | 外框、底栏分隔线（蓝灰） |
| `LAMP_OFF` | `#1A2148` | 灯条段熄灭态 |
| `OK_GREEN` | `#3FF08F` | 仅用于连接稳定指示，不得作它用 |

组件规则：

- **面板：** 2 px `PANEL_GLOW` 边框＋外发光＋内发光＋四角括号。括号为对角双角（左上与右下），2 px，`STATUS` 色。
- **顶栏：** 左侧模式名（`LABEL` 发光）＋右侧电池图标与百分比（`STATUS`），数值取自 `bsp_battery_soc()`。
- **页标题（h1）：** `STATUS` 色、微斜切（约 −3°）；其下副标题为小字宽字距的 `FRAME` 色调文字。
- **灯条（状态指示）：** 段尺寸 12×5 px，点亮有两种语义：橙色发光（`PANEL_GLOW`）与青色发光（`LABEL`）；熄灭段用 `LAMP_OFF`。
- **底栏按键图例：** 按键名 `STATUS` 色＋动作 `TEXT` 色，全英文，如 `OK FULLSCR`、`OK HOLD EXIT`、`OK PAIR`、`DOWN SLOT`。图例中的 HOLD 对应 requirements 定义的 ≥800 ms 长按阈值。

## 3. 布局系统（Layout System）

竖屏 240×320 px，参考分区：

| 分区 | Y 范围 | 内容 |
|---|---|---|
| 顶栏 | 0–32 | 模式名（左）、电池图标＋百分比（右） |
| 内容区 | 32–296 | h1、副标题、纵向堆叠的面板 |
| 底栏 | 296–320 | 按键图例，以 1 px `FRAME` 分隔线隔开 |

规则：

- 安全边距：四边 **10 px**，任何文字或面板边缘不得越过。
- 面板在内容区内自上而下等间距堆叠；视觉样机按目标屏的 0.8 倍（192×256）绘制，样机像素值换算到设备时乘以 1.25。
- 参考字号（除注明外均为样机换算值）：顶栏文字约 11 px、h1 约 16 px、副标题约 8 px、面板标签约 8 px、底栏图例约 8 px；第 4 章的计时器 36 px 与页码 16 px 为设备规范值。
- 电池组件不得与顶栏其它内容重叠；读数不可用时按第 8 章降级。

## 4. 页面规格（Page Specifications）

所有页面进入时一次性绘制全屏底纹（网格＋扫描线），此后仅刷新脏区（见第 5 章）。

### 4.1 Standby（待机/启动）

元素清单：

- 顶栏：`PC-CTRL`（左，青色发光）＋电池图标/百分比（右）。
- h1 `STANDBY`（斜切荧光黄）；副标题如 `PRESENTATION CORE v1.0`。
- 面板 1 `HOST LINK`：标签行状态字（`SEARCHING…` / `CONNECTED` / `DISCONNECTED`），中部大字（20–24 px）在启动阶段显示 `STARTING` / `PLEASE WAIT`，连接后显示主机名；下方灯条。
- 面板 2 `PROFILE`：单行标签，取值 `WINDOWS` / `MACOS` / `LINUX`（荧光黄，靠右）。
- 底栏：`OK PAIR/PRESENT / UP MENU / DOWN SLOT`。
- 菜单：经 `UP` 进入的独立 8 项列表页；选中项以橙底黑字高亮，`OK` 短按进入/确认选中项，`OK` 长按返回待机主页。

状态变体：`SEARCHING…`（灯条动效）、`CONNECTED`（显示主机名、灯条常亮）、`DISCONNECTED`（仅状态字、灯条熄灭）。

### 4.2 Present（演示，核心页）

元素清单：

- 顶栏：`PRESENT`＋电量。
- h1 `PRESENT MODE`；副标题 `SLIDE CONTROL ACTIVE`。
- 面板 1 `SPEECH TIMER`：标签行右侧为 `RUN` 状态；**36 px 青色发光数字**为本页主视觉（规范字号）。每秒仅数字脏区重绘。
- 面板 2 `SLIDE`：**16 px 橙色发光页码**（规范字号）。页码为本地估算——主机不上报总页数，故永不显示 `x/y` 形式。提示行：`▲ UP · ▼ DOWN`。
- 面板 3 `HOST LINK`：单行标签，取值 `STABLE`（荧光黄）——此处是唯一可用 `OK_GREEN` 指示连接稳定的位置。
- 底栏：仅 `OK FULLSCR` 与 `OK HOLD EXIT`。双击槽位在事件词汇表中保留但无绑定动作，底栏图例相应留空（与 requirements 的 Non-Goals 一致）。

状态变体：断连时面板 3 切换为红色 `LOST` 并闪烁提示（告警红为状态局部色，不在基线令牌集内）。本模式禁用锁屏与音量，图例中永不出现。

### 4.3 Pairing（配对）

元素清单：

- 顶栏：`PAIRING`＋电量。
- h1 `BLE HID`；副标题 `DISCOVERABLE · SLOT n/3`。
- 面板 1 `HOST LINK`：标签行取值 `OPEN`；中部 `SEARCHING`（16 px）；副行 `SELECT "PC-CTRL" ON HOST`；灯条**橙青交替**闪烁。
- 面板 2 `BOUND SLOTS`：标签行，取值 `x/3`。
- 底栏：`OK CANCEL / DOWN SLOT`。

状态变体：广播中（灯条闪烁）与连接进入（灯条转为待机样式）。

### 4.4 Action Feedback / Media（动作反馈/媒体）

本页含两个子状态：

- **锁屏反馈：** 面板标签行 `COMMAND` / `WIN+L`，中部大字 `LOCKED`，副行 `PROFILE: WINDOWS`。`COMMAND` 行随当前主机档案显示对应组合键（`WIN+L` / `CTRL+CMD+Q` / `SUPER+L`），`PROFILE` 行显示档案名（`WINDOWS` / `MACOS` / `LINUX`）。显示 **1.5 s** 后自动返回待机。
- **媒体模式：** 面板标签行 `MEDIA MODE` / `VOL nn`（两位音量值）。底栏：`UP VOL+ / DOWN VOL- / OK PLAY`；OK 长按返回待机。

锁屏只能从待机模式触发（锁屏反馈页同样只在待机触发后显示）——演示模式与媒体模式中永不出现。

## 5. 渲染纪律（Rendering Discipline）

来自 BSP 的硬约束：单缓冲 240×20 行、`double_buffer = false`、无 TE。全屏一帧为 240×320×2 B = 150 KB，按 **16 批** 240×20 刷出；40 MHz SPI 下理论全屏重绘上限约 30 fps，叠加 CPU 渲染后更低。

规则：

1. **一次性底纹：** 页面进入时绘制一次网格/扫描线底纹（16 批 × 240×20），其后各帧只碰脏区。动效元素帧率目标 **20–30 fps**。
2. **脏区预算表：**

| 元素 | 脏区 | 说明 |
|---|---|---|
| 扫描线亮带 | 240×2 px（RGB565 下 960 B），每帧 < 1 KB | `lv_anim` y 轴、周期 2–4 s |
| 计时器数字 | 1–4 KB/秒 | 每秒仅数字矩形重绘 |
| 页码 | 仅翻页时更新 | 无周期刷新 |
| 连接/电量 | 仅事件驱动 | 无轮询重绘 |

3. **禁止项：** 每帧全屏动画；改用双缓冲；半屏高对比持续动效（无 TE 时撕裂最敏感的构图）；常驻全屏闪烁。
4. **转场：** 一次性黑场过渡——先清屏并降背光，再载入绘制新页，最后恢复背光。不做持续转场动画。

算账依据来自固件开发计划的 FUI 渲染预算章节（项目工作区文档，位于仓库外；仅文字引述，不设链接）。量化验收值：见 requirements.md。

## 6. 字体素材（Font Assets）

- 字体：HUD 像素字体；参考候选为 Press Start 2P（OFL 授权**待核实**，核实不通过则替换为同等授权的像素字体）。
- 子集化：`lv_font_conv`，仅打包界面实际用到的约 **70 个英文字形**，16 px、4 bpp。
- 计时器数字子集：独立的 **36 px 数字子集**供演讲计时器使用（仅 0–9 与冒号共 11 字形），4 bpp，估算 **≤2 KB Flash**。
- 预算：**16 px 子集 6–10 KB Flash ＋ 36 px 数字子集 ≤2 KB Flash**；存 Flash memory-mapped，RAM 占用 ≈ 0（本板无 PSRAM）。
- 放置：字体二进制与生成的 C 数组入 `assets/fonts/`，并按 [assets/fonts/README.md](../../../assets/fonts/README.md) 的规则登记（去向、命名、集成方式、来源/授权）。
- **明确不引入 CJK 字库。** 屏幕文字全英文；省去中文点阵子集约 30–45 KB Flash 开销，也避免缺字回退。

## 7. 动效与反馈（Motion and Feedback）

- **按键音：** 每个被接受的按键事件经音频通路（`components/bsp` 音频）播放短促提示音；无效按键用区别明显的低音。验收标准：见 requirements.md。
- **扫描线动画：** 一条 240×2 px 亮带缓慢下移，`lv_anim` y 轴循环、周期 2–4 s；只弄脏其经过的窄带。
- **灯条节奏：** 待机搜索＝渐进填充；配对＝橙青交替闪烁；连接/稳定＝常亮。闪烁半周期不短于 500 ms，保证脏区极小。
- **动作反馈时长：** 锁屏/媒体反馈面板显示 **1.5 s**，随后经一次性黑场过渡恢复原页面。
- **断连闪烁：** 红色 `LOST` 状态以慢节奏闪烁，闪烁重绘仅触及标签矩形。

## 8. 降级（Degradation）

- **电量读数 `-1`：** `bsp_battery_soc()` 返回 `-1` 表示不可用。顶栏只画电池图标外框、不画百分比数字——绝不显示 `-1` 或 `0%`。
- **断连：** 演示页面板 3 切为红色 `LOST` 并闪烁（见 4.2）；待机页显示 `DISCONNECTED`。页码/计时器画面冻结在最后值。
- **显示初始化失败：** 应用不得阻塞或崩溃；跳过全部 UI 工作，尽可能保留按键/蓝牙功能，并以日志暴露失败。UI 层不得以重试循环反复冲击 SPI 总线。
- **LVGL 锁纪律：** 非 LVGL 上下文访问 LVGL 对象必须持有 `bsp_lvgl_lock()` / `bsp_lvgl_unlock()`（见 `docs/development/agent-guide.zh_CN.md` 运行时不变量）。
